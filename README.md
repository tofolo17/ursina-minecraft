# UrsinaMinecraft
 
## What will you find in this repository?

A simple Minecraft clone built with Ursina engine. In this prototype:
* Blocks can be added and broken;
* The map is procedurally generated.

To do this, I had to read some chapters of the book [The Nature of Code](https://natureofcode.com), by [Daniel Shiffman](https://en.wikipedia.org/wiki/Daniel_Shiffman), and go deeper through Perlin's noise using Jupyter Notebooks. In addition, I learned the basics of Ursina through its own [documentation](https://www.ursinaengine.org/documentation.html). 

## O que você encontrará neste repositório?

Um clone simples do jogo Minecraft construído com a biblioteca Ursina. Neste protótipo:
* Blocos podem ser adicionados e quebrados;
* O mapa é gerado proceduralmente a cada execução.

Para tal, li alguns capítulos do livro [The Nature of Code](https://natureofcode.com), de [Daniel Shiffman](https://en.wikipedia.org/wiki/Daniel_Shiffman), e me aprofundei através de Jupyter Notebooks no conteito de ruído de Perlin. Além disso, conheci o básico da Ursina através de sua própria [documentação](https://www.ursinaengine.org/documentation.html).
